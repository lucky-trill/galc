# Global Automatic Level Change (GALC)

This modules handles automatically changing a token's level based on its elevation. It also includes options for:

1. viewing token elevation as an absolute value instead of a value relative to level and
2. level navigation tweaks, including the option to provide a full navigation to players.

All of these options can be turned off, turned on, and tailored on a per-scene and per-level basis via a variety of settings.
